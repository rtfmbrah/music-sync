# Architecture Decision Records

ADRs record significant, binding choices. Status is `Proposed`, `Accepted`,
`Deprecated`, or `Superseded`. To change an accepted decision, add a new ADR that
explicitly supersedes it and describes migration; do not rewrite history.

- [0001: Rust library-first workspace](0001-rust-library-first-workspace.md)
- [0002: SQLite is application state](0002-sqlite-application-state.md)
- [0003: preservation and separated identity](0003-preservation-and-separated-identity.md)
- [0004: external adapters and source-preserving audio](0004-external-adapters-and-source-audio.md)
- [0005: agent-native repository truth](0005-agent-native-repository.md)

New records use the next number and contain context, decision, consequences, and
supersession links where applicable.
